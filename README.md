# GameDeals — скидки на PC-игры

Учебный проект: **Задание 1**, Фасттрек по предмету «Кроссплатформенная разработка».
Автор: **Дьяченко Антон**.

SPA для поиска скидок на PC-игры: каталог, страница игры и аналитика на данных
[CheapShark API](https://apidocs.cheapshark.com/). React, TypeScript, Vite. Деплой на GitHub Pages.

## Запуск

```bash
corepack enable
pnpm install
pnpm run dev
```

## Проверки

- `pnpm run test` — юнит- и компонентные тесты (Vitest);
- `pnpm run test:e2e` — сквозные тесты на моках CheapShark (Playwright); `E2E_LIVE=1` — против живого API;
- `pnpm run test:live` — проверка zod-схем на реальном ответе CheapShark;
- `pnpm run lint`, `pnpm run format:check` — линтер и форматирование;
- `pnpm run deadcode` — неиспользуемые файлы и экспорты (knip);
- `pnpm run build && pnpm run size` — сборка и бюджет размера бандла.

## Что умеет

- каталог: поиск с подсказками, фильтры по магазинам, цене, скидке, Metacritic и тегам,
  сортировки и бесконечная лента;
- страница игры: предложения магазинов, минимум за всё время, динамика цены, избранное;
- аналитика: KPI, графики по выборке лучших сделок и экспорт CSV;
- переключение цен между долларами и рублями (конвертация по курсу, ориентировочно).

## Данные

Цены и магазины отдаёт CheapShark. Теги, владельцы и дневные снапшоты цен собирает GitHub Actions
(`update-data.yml`) и складывает в `public/data`. Цены кэшируются примерно на час и обновляются по
запросу (есть кнопка ручного обновления) — так сайт бережёт лимит API. У CheapShark нет истории цен,
поэтому график динамики строится по собственным снапшотам. В долларах — как в источнике, рубли —
ориентировочная конвертация по курсу без учёта региональных цен и налогов.
